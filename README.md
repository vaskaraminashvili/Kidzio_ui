# Kidzio UI

A static, mobile-first prototype of a space-themed quiz app for kids aged 7–12.
It uses plain HTML, Tailwind CSS (CDN) and Alpine.js (CDN), with no build step.

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Set **Source** to **Deploy from a branch**.
3. Choose branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. After 1–3 minutes the site is live at `https://vaskaraminashvili.github.io/Kidzio_ui/`.

Every push to `main` redeploys the site.
